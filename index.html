Install

  1. Badges: Settings > Playback > Versions > Badges > Edit. Delete all existing badges, paste badges.json in Import, click Import, then Save. The row should read "47 badges of your own".
  2. CSS: Settings > Theme > Custom CSS. Paste badges.css at the end, Apply CSS, then Keep within 15 s. Required for the image badges (same height and radius as text badges).
  3. Quick filters: Settings > Playback > Versions > Quick filters > Edit. Delete existing filters, paste quick-filters.json in Import, Save.
  4. Quit and relaunch the app so images reload.

T1, T2, T3 and LQ need the Vidhin ranked stream expressions. RD, TB, AD and EN need four ranked stream expressions named "Ready RD", "Ready TB", "Ready AD", "Ready EN" (see README). Remove badges you do not use before importing.

badges.css

/* AIOStreams image badges: the app draws the frame, the image fills it.
   One height and one corner radius for every badge (text and image).
   Settings > Theme > Custom CSS > paste at the end > Apply CSS > Keep. */
[data-ui='version-badge'] {
  height: 1.375rem !important;
  border-radius: 5px !important;
  box-sizing: border-box !important;
}
img[data-ui='version-badge'] {
  width: auto !important;
  padding: 0 !important;
  display: block;
}
[data-ui='version-badge']:has(> img) {
  padding: 0 !important;
  overflow: hidden;
}
[data-ui='version-badge'] > img {
  height: 100% !important;
  border-radius: 0 !important;
  width: auto !important;
  max-height: none !important;
  display: block;
}
[data-ui='version-badges'] { align-items: center; }
