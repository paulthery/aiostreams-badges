# aiostreams-badges

Image badges for AIOStreams version lists. Gold = optimal, grey = acceptable.
Borderless transparent PNG (6x) + SVG source, framed by the app border. Typeface: Inter.

## Files

    codec/  h265  av1  10bit  (gold)
            h264  vp9         (grey)
    hdr/    hdrdv  dv  hdr10plus  hdr10  (gold)
            hlg  sdr                     (grey)

## Use

Raw URL pattern for the `image` field:

    https://raw.githubusercontent.com/paulthery/aiostreams-badges/main/<folder>/<name>.png

`badges.json` is the full badge set (text + image badges), ready to import.
